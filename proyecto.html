Proyecto final: construye tu web

Aplica lo aprendido en una web pequeña, comprueba su funcionamiento y comparte tu proceso.

En esta lección

  1. El reto
  2. Plan de trabajo
  3. Revisa tu entrega
  4. Entrega y valoración
  5. Tu turno

01. Tu propia web de aprendizaje

Adapta WebLab a un tema que conozcas: una guía de tu localidad, un curso básico o un sitio de recursos para tu clase. Mantén una estructura sencilla que puedas explicar.

  • Al menos tres páginas HTML enlazadas con un menú común.
  • Una hoja CSS compartida y un diseño responsive.
  • Una interacción breve con JavaScript vainilla.
  • Imágenes locales con texto alternativo y créditos cuando corresponda.
  • README con objetivos, estructura, ejecución y autores.

02. Construye en pasos pequeños

  1. Planifica: escribe los contenidos y dibuja un esquema de las páginas.
  2. Estructura: crea HTML semántico y comprueba las rutas.
  3. Diseña: aplica estilos comunes y adapta el layout.
  4. Interactúa: añade un evento sencillo y prueba con teclado.
  5. Versiona: guarda cada mejora con un commit descriptivo.
  6. Comparte: publica la rama y pide revisión con un pull request.

Un buen commit cuenta una sola mejora: «Añade texto alternativo a las imágenes» resulta más útil que «Cambios».

03. Antes de entregar

0 de 7 comprobaciones completadas.

Lista de apoyo: marca solo lo que hayas comprobado. Las marcas se reinician al recargar; no es una calificación automática.

04. Enseña lo que has aprendido

Entrega el enlace del repositorio de GitHub y, si lo publicas, el enlace de GitHub Pages. Añade al README una breve explicación de tus decisiones y de la mejora que quieres hacer después.

La revisión en clase se centra en estructura y contenidos, diseño adaptable, accesibilidad, interacción y claridad del historial. Debes poder explicar cómo se enlazan los archivos y qué cambió en un commit.

Vuelve a Git / GitHub si necesitas preparar la entrega.

Tu turno

Una pequeña práctica

Elige una mejora de tu web, descríbela en una issue y resuélvela en una rama. Entrega el enlace al repositorio y explica un commit concreto durante la revisión en clase.

Ver una pista

Una buena primera issue: «Añadir una página de recursos con enlaces comentados». Define cuándo estará terminada: página accesible desde el menú, estilos compartidos y enlaces comprobados.
