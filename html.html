HTML: la estructura

Organiza el contenido con etiquetas semánticas y enlaza las páginas de tu sitio.

En esta lección

  1. Estructura
  2. Enlaces e imágenes
  3. Formularios
  4. Tu turno

01. Contenido con significado

HTML es un lenguaje de marcas. Describe qué es cada parte del contenido: un título, un párrafo, una lista o un enlace. Las etiquetas no se eligen por su aspecto, sino por su función.

header agrupa la cabecera; nav, la navegación; main, el contenido principal; y footer, el pie. Usa un h1 que identifique la página y h2 para sus secciones.

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Mi primera web</title>
</head>
<body>
  <header><h1>Mi primera web</h1></header>
  <main>
    <section>
      <h2>Sobre mí</h2>
      <p>Estoy aprendiendo HTML en 1.º DAM.</p>
    </section>
  </main>
  <footer><p>Proyecto de LMSGI</p></footer>
</body>
</html>

02. Conecta páginas y recursos

El atributo href indica el destino de un enlace. src indica el archivo de una imagen. Las rutas relativas se calculan desde el archivo que las usa; respeta mayúsculas y minúsculas, también en GitHub Pages.

<a href="css.html">Aprender CSS</a>
<img src="img/web-stack.svg"
     alt="HTML, CSS y JavaScript forman las tres capas de una web."
     width="560" height="380">
<ul>
  <li>Estructurar con HTML</li>
  <li>Diseñar con CSS</li>
  <li>Interactuar con JavaScript</li>
</ul>

Describe en alt la información relevante de una imagen. Si es puramente decorativa, usa alt="". Escribe enlaces con un destino comprensible, como «Aprender CSS».

03. Etiquetas que ayudan a todos

Un campo necesita una etiqueta asociada. El atributo for debe coincidir con su id; name identifica el dato cuando se envía un formulario.

<form action="/contacto" method="post">
  <label for="nombre">Nombre</label>
  <input id="nombre" name="nombre" type="text" required>
  <button type="submit">Enviar</button>
</form>

Este ejemplo necesitaría un servidor que gestione /contacto. WebLab es una web estática y no incluye envío de datos. Los botones de las demostraciones usan type="button".
