CSS: dale forma

Colores, espacio y layouts que funcionan tanto en un móvil como en un ordenador.

En esta lección

  1. Selectores
  2. Modelo de caja
  3. Flexbox y Grid
  4. Tu turno

01. Una hoja, muchas páginas

CSS define la presentación. Enlaza la misma hoja de estilos desde todas las páginas para mantener colores, espacios y tipografía coherentes.

<!-- Dentro de head -->
<link rel="stylesheet" href="css/estilos.css">

Un selector de etiqueta afecta a todos los elementos de ese tipo. Una clase reutilizable comienza por un punto. La cascada resuelve qué regla se aplica según origen, importancia, especificidad y orden.

body {
  font-family: system-ui, sans-serif;
  color: #172333;
}
.tarjeta {
  background: white;
  border-radius: 12px;
}

02. Todo elemento ocupa una caja

El contenido tiene espacio interior (padding), borde (border) y separación exterior (margin). Con box-sizing: border-box, el ancho declarado incluye padding y borde.

El contenido es el mismo. Cambia el espacio interior.

03. Un diseño que se adapta

Flexbox organiza elementos principalmente en una dirección: por ejemplo, un menú que puede saltar de línea. Grid distribuye filas y columnas. Una media query permite cambiar el layout según el ancho disponible.

.menu {
  display: flex;
  gap: 12px;
  flex-wrap: wrap;
}
.tarjetas {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}
@media (max-width: 640px) {
  .tarjetas { grid-template-columns: 1fr; }
}

Prueba con ventanas pequeñas y zoom al 200 %. Evita textos diminutos y comprueba que el foco del teclado se ve. En esta web los bloques de código pueden desplazarse horizontalmente sin ensanchar toda la página.
