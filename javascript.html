JavaScript: añade interacción

Una referencia al elemento, un evento y un cambio visible: tu primera interacción con el DOM.

En esta lección

  1. Variables y carga
  2. DOM y eventos
  3. Depuración
  4. Tu turno

01. Guarda datos y carga tu script

JavaScript añade comportamiento. Usa const para referencias que no vas a reasignar y let para valores que sí cambian. Un texto es una cadena; un número permite hacer cálculos.

const curso = "1.º DAM";
let actividadesCompletadas = 0;
actividadesCompletadas = actividadesCompletadas + 1;
console.log(curso, actividadesCompletadas);

Enlaza el script con defer: se ejecutará después de analizar el HTML. Así podrá encontrar los elementos de la página.

<script src="js/app.js" defer></script>

02. Selecciona, escucha, modifica

El DOM es la representación del documento que ofrece el navegador. querySelector encuentra un elemento, addEventListener escucha una acción y textContent cambia el texto.

<button id="greeting-button" type="button">Saludar</button>
<p id="greeting-message" aria-live="polite">
  Pulsa el botón para saludar.
</p>
const greetingButton = document.querySelector('#greeting-button');
const greetingMessage = document.querySelector('#greeting-message');

if (greetingButton && greetingMessage) {
  greetingButton.addEventListener('click', () => {
    greetingMessage.textContent =
      '¡Hola, DAM! Has actualizado el DOM con JavaScript.';
  });
}

La comprobación if evita errores en páginas que no tienen estos elementos. aria-live="polite" anuncia el cambio a quienes usan un lector de pantalla.

Pruébalo aquí

Pulsa el botón para saludar.

03. Observa antes de cambiar

  1. Abre las herramientas de desarrollo del navegador y entra en la consola.
  2. Si hay un error, lee el archivo y el número de línea que indica.
  3. Comprueba que el selector coincide con el id del HTML.
  4. Guarda, recarga y vuelve a probar el botón con ratón y teclado.

Mantén los contenidos y los enlaces en HTML. JavaScript debe mejorar la experiencia: el curso debe seguir siendo legible cuando el script no esté disponible.

Tu turno

Una pequeña práctica

Añade un segundo botón que restablezca el mensaje del ejemplo a «Pulsa el botón para saludar».

Recorre ambos botones con el teclado. Comprueba que no hay errores en la consola del navegador.

Ver una pista

Asigna un identificador único al botón, selecciónalo con document.querySelector() y escucha su evento click. Modifica textContent del mismo párrafo.
